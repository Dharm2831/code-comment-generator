#Writes the comment your function is missing.

Paste a Python or Java function and a fine-tuned Transformer writes a one-line English comment describing what it does. Built and trained on a laptop GPU as a Deep Learning mini project.

Source code on GitHub Trained model on Hugging Face

How it works

  1. Clean real code

    406,121 Python and Java functions with their documentation, from the CodeXGLUE code-to-text dataset. The docstring is removed from the code and only the first sentence of each comment is kept as the target.

  2. Fine-tune a Transformer

    CodeT5-small, a 60-million-parameter encoder-decoder already pre-trained on code, is trained for three epochs to turn a function into its comment. It took 3.5 hours on an RTX 5050 laptop GPU.

  3. Comment a whole file

    The app finds every function in pasted code, generates a comment for each with beam search, and inserts it above the function: a # comment for Python, a /** */ comment for Java.

Results on 2,000 unseen functions

BLEU and chrF compare the generated comment with the human one (0–100, higher is better). Token accuracy is the share of comment words predicted correctly.

ModelBLEUchrFToken accuracyTraining time
CodeT5-small, not fine-tuned0.2811.5218.8%none
Fine-tuned on 60,000 functions8.4729.9648.7%25 min
Fine-tuned on 406,121 functions8.9830.8450.2%212 min

Fine-tuning produced almost all of the gain; seven times more data added half a BLEU point. These scores use strict corpus-level BLEU, so they are not comparable with the smoothed BLEU reported in research papers.

What it can't do yet

  • It writes one summary sentence per function, not line-by-line comments or parameter documentation.
  • Comments are often shorter and more generic than a human's, and sometimes wrong, so a developer should review them.
  • Only the first 256 tokens of a function are read, so the end of very long functions is ignored.
  • Only Python and Java are supported.

Run it on your computer

You need Python 3.10 or newer. A GPU is only needed for training; the app runs on a CPU. Full instructions are in the README.

# get the code and install
git clone https://github.com/Dharm2831/code-comment-generator.git
cd code-comment-generator
pip install torch -r requirements.txt

# use the trained model from Hugging Face and start the app
set MODEL_ID=Dh4rm2831/code-comment-generator
python app.py

On macOS or Linux, write export MODEL_ID=... instead of set MODEL_ID=.... Then open http://127.0.0.1:7860.
